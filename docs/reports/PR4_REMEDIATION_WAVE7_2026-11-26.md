### LND-R4-01 — черновик поддержки

Состояния конечного автомата: `loading → clean → dirty → saving → saved | error`.

- Пока `GET /support/threads/:id/draft` не завершился, таймер записи **не вооружается**: ни PUT, ни DELETE не уходят.
- Ошибка чтения — это `error` со scope `load`, а не «пользователь очистил поле»: удалить черновик при неизвестном состоянии сервера нельзя.
- `DELETE` уходит только когда поле очищено **после** завершённой загрузки **и** сервер действительно хранит черновик.
- `savedBody` обновляется только в ветке успеха: неуспешный PUT оставляет статус «Не сохранено», сообщение уходит оператору через тост, кнопка «Повторить сохранение» досылает тот же текст.
- Поздний ответ сервера не затирает текст оператора: локально набранный ответ всегда выигрывает.

### LND-R4-03 — деньги партнёра

```
accruedKopeks     — все начисления партнёра за всю историю (не страница)
disputedKopeks    — нетто спорного удержания (GREATEST(0, начисление − зачтённые кредиты))
grossPayableKopeks = accrued − disputed
paidKopeks        — выплаты в состояниях approved | paid
reservedKopeks    — выплаты в состояниях scheduled | pending
availableKopeks   = grossPayable − paid − reserved
```

`queryPartnerBalance` — единственный источник этих чисел: его читают и панель партнёра, и
авторизация выплаты. Ошибка `PAYOUT_EXCEEDS_PAYABLE` сохранила прежний набор полей.

### LND-R4-07 — здоровье worker'а

| Элемент | Значение |
|---|---|
| Файл heartbeat | `WORKER_HEARTBEAT_FILE`, по умолчанию `./.worker-heartbeat`; в compose — `/app/.worker-heartbeat` |
| Содержимое | JSON: `lastSuccessAt`, `lastSuccessSummary`, `lastFailureAt`, `lastFailureMessage`, `updatedAt` (запись атомарная) |
| Предел возраста | `WORKER_HEARTBEAT_MAX_AGE_MS`, иначе 3 × `WORKER_INTERVAL_MS` (по умолчанию 90 000 мс) |
| Коды выхода пробы | `0` — последний успешный цикл свежий; `1` — нет файла, нет успешного цикла, нечитаемая метка или цикл старше предела |
| Docker | api — HTTP readiness; worker — `node scripts/worker-health.mjs` (интервал 30 с, старт-период 60 с) |
| Деплой | `scripts/deploy-hetzner.sh` и `scripts/deploy-preview.sh` ждут здоровья worker'а и падают с внятной ошибкой, если цикла не было |

Неуспешный цикл **не** обновляет метку последнего успешного: зависший worker выглядит
нездоровым, а не «просто простаивает».
