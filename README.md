# Laundry

Сервис агрегированной стирки, глажки и химчистки с забором и возвратом вещей из многоквартирных домов.

## Ключевая дифференциация
Два режима сервиса: **Эконом** — быстрая пакетная приёмка повседневных вещей; **Защищённый** — подробная поштучная опись, фиксация состояния и расширенный доказательный процесс для дорогих/деликатных вещей. Это разные процедуры и цены, но не попытка отменить обязательные права потребителя.

## Принципы
- Никаких доплат и изменения способа обработки без согласия клиента.
- Каждая передача между клиентом, курьером, сортировочным узлом и прачечной фиксируется событием.
- Видео — дополнительное доказательство, не замена квитанции, описи, согласия и обязательных документов.
- Персональные данные и медиа собираются минимально, доступ и сроки хранения контролируются.
- Сначала проектируем сценарии, исключения, операционные процессы и юридическую модель; затем реализацию.
- Условия ответственности и оферта должны пройти проверку российского юриста; нельзя договором исключать императивную ответственность или считать незадокументированную вещь «несуществовавшей».
