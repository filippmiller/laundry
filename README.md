# Laundry — Чисто

Сервис стирки, глажки и химчистки с забором и возвратом вещей из многоквартирных домов. Два тарифа: **Эконом** (мешок, пломба, вес) и **Защищённый** (поштучная опись, состояние, доказательства).

**Статус:** работающий демонстрационный вертикальный срез (не продакшен). Суммы, тарифы и документы демонстрационные; юридические и финансовые гейты не пройдены.

## Что уже работает
- PostgreSQL-схема из 12 групп + SQL- triggers append-only и баланса журналов (78 таблиц, 14 миграций).
- Тенантная авторизация из серверной сессии, RBAC на уровне маршрутов и сервисов, проекции полей по роли, демо-вход только вне production.
- Атомарные брони слотов, expiry-worker, сверка и ремонт ёмкости с аудитом.
- Калькуляция immutable-квот, заказ, бронирование только привязанных слотов, отмена с освобождением ёмкости и перенос брони одной транзакцией.
- Идемпотентность всех мутаций с привязкой ключа к актору; лимиты частоты (общий, вход, вебхуки).
- Приёмка курьером (мешок/пломба/вес, офлайн-синк сканов), приёмка прачечной с расхождениями, обработка, полный QC, точная выдача комплекта, частичная доставка с повторным визитом, претензии с legal hold.
- Двойная запись в журнал, фиктивный платёжный адаптер с блокировкой повторного capture и возвратов, подписанный вебхук-inbox с обработчиком и сверкой, chargeback-статус, партнёрские начисления и споры.
- Курьер: офлайн-очередь сканов в IndexedDB, привязка устройства к курьеру, пересчёт хеша события, проверка контейнера и пломбы по заказу.
- Поддержка: обращения клиента по заказу, ответы поддержки, закрытие; отзывы по завершённым заказам, лайки и модерация с аудитом.
- Администрирование: участники и роли с аудитом, отзыв сессий, журнал аудита и очередь антифрод-сигналов (только просмотр).
- Fastify API с Zod-валидацией и генерируемым OpenAPI 3.1; React SPA с экранами клиента, курьера, операций, поддержки и администрирования.
- 188 автоматических тестов (юнит + PostgreSQL + HTTP API) в 29 файлах, включая регрессии P0/P1 из независимого аудита, и браузерный smoke-тест (11 проверок в браузере). Актуально на 2026-11-18; состав и честный статус сценариев — в `docs/coverage/PR3_SCENARIO_STATUS.json`.

## Быстрый старт (Windows/local)
```bash
npm ci
npm run dev:db          # в отдельном терминале: PostgreSQL 18 на :55432
$env:DATABASE_URL='postgres://postgres:postgres_test_only@127.0.0.1:55432/laundry'
npm run db:migrate
npm run db:seed
npm run web:build
npm run start:api       # http://localhost:3000 (SPA + /api/v1)
```
Демо-пользователи выводятся `npm run db:seed`. Вход: телефон + роль; организация берётся из сессии.
