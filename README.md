# Laundry — Чисто

Сервис стирки, глажки и химчистки с забором и возвратом вещей из многоквартирных домов. Два тарифа: **Эконом** (мешок, пломба, вес) и **Защищённый** (поштучная опись, состояние, доказательства).

**Статус:** работающий демонстрационный вертикальный срез (не продакшен). Суммы, тарифы и документы демонстрационные; юридические и финансовые гейты не пройдены.

## Что уже работает
- PostgreSQL-схема из 12 групп + SQL- triggers append-only и баланса журналов (37 таблиц).
- Тенантная авторизация из серверной сессии, RBAC, демо-вход только вне production.
- Атомарные брони слотов, expiry-worker, сверка и ремонт ёмкости с аудитом.
- Калькуляция immutable-квот, заказ, адаптация слота, идемпотентность всех мутаций.
- Приёмка курьером (мешок/пломба/вес, офлайн-синк сканов), приёмка прачечной с расхождениями, обработка, QC, частичная доставка, претензии с legal hold.
- Двойная запись в журнал, фиктивный платёжный адаптер, возвраты, вебхук-inbox, партнёрские начисления и споры.
- Fastify API с Zod-валидацией и генерируемым OpenAPI 3.1; React SPA для клиента, курьера и операционных ролей.
- 31 автоматический тест (юнит + PostgreSQL + HTTP API) и браузерный smoke-тест.

## Быстрый старт (Windows/local)
```bash
npm ci
npm run dev:db          # в отдельном терминале: PostgreSQL 18 на :55432
$env:DATABASE_URL='postgres://postgres:postgres_test_only@127.0.0.1:55432/laundry'
npm run db:migrate
npm run db:seed
npm run web:build
npm run start:api       # http://localhost:3000 (SPA + /api/v1)
```
Демо-пользователи выводятся `npm run db:seed`. Вход: телефон + роль; организация берётся из сессии.
